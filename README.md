# Retail-Sales-Performance-Dashboard-Task-2
📌 Project Overview

This project was completed as part of the Elevvo Data Analytics Internship Program.

The objective of this task was to build an interactive Retail Sales Performance Dashboard using a cleaned retail dataset. The dashboard provides key business insights such as revenue trends, regional performance, and top-performing products.

📊 Dashboard Features
🔹 Key Performance Indicators (KPIs)

Total Revenue: 13M

Total Orders: 25K

Total Profit: 1.47M

🔹 Visualizations Included

📍 Total Revenue by Region

📦 Total Revenue by Product Name

📅 Total Revenue by Order Date (Trend Analysis)

🎯 Region Filter (Interactive Slicer)

🛠️ Tools & Technologies Used

Power BI

Data Cleaning & Transformation

Data Modeling

Interactive Filters & Slicers

Business KPI Analysis

Identified highest revenue-generating regions.

Analyzed top-performing products.

Compared profitability across different regions.
